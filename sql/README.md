# SQL Analysis

## Цель анализа

Провести анализ интернет-магазина Olist с помощью SQL и ответить на основные бизнес-вопросы:

- как меняются продажи во времени;
- какие факторы влияют на рост и падение выручки;
- какие товары и категории наиболее значимы для бизнеса;
- как ведут себя клиенты;
- где возникают проблемы с доставкой;
- какие способы оплаты используются;
- как клиенты оценивают покупки.

## Структура анализа

### 01. Business Overview

Общая картина бизнеса:

- количество заказов;
- количество клиентов;
- количество товарных позиций;
- количество товаров;
- количество продавцов.

### 02. Sales Analysis

Анализ динамики продаж:

- количество заказов;
- выручка;
- средний чек;
- изменение выручки месяц к месяцу.

Основные результаты:

- наиболее значительный рост выручки наблюдался в феврале 2017 года — **+105.55%**;
- рост был обеспечен увеличением количества заказов, несмотря на снижение среднего чека;
- в ноябре 2017 года выручка выросла на **52.10%**, также главным образом за счёт увеличения количества заказов;
- наиболее существенное снижение выручки среди полноценных периодов наблюдалось в декабре 2017 года — **−26.36%**.

### 03. Product Analysis

Анализ структуры продаж по товарам и категориям:

- топ-10 товаров по выручке;
- 10 товаров с минимальной выручкой;
- топ-10 категорий по выручке;
- 10 категорий с минимальной выручкой;
- количество заказов и товарных позиций по категориям;
- средняя цена товарной позиции по категориям;
- ABC-анализ категорий;
- ABC-анализ товаров.

Основные результаты:

- **16 из 72 категорий формируют около 80% выручки**;
- среди лидеров по выручке — `health_beauty`, `watches_gifts` и `bed_bath_table`;
- около **24.3% товаров формируют 80% выручки**;
- группа A включает **7 995 товаров** из 32 951;
- группа B — **4 075 товаров**;
- группа C — **20 881 товар**, или около **63.4% ассортимента**.

### 04. Customer Analysis

Анализ клиентской базы и повторных покупок:

- распределение клиентов по количеству заказов;
- анализ статусов заказов и определение методологии «состоявшейся покупки»;
- Repeat Purchase Rate среди клиентов с хотя бы одной завершённой (delivered) покупкой;
- топ клиентов по выручке;
- когортный Retention Analysis.

Основные результаты:

- в клиентской базе **96 096** клиентов, из них **93 358** имеют хотя бы один `delivered`-заказ;
- **90 557** клиентов совершили только одну завершённую покупку;
- **2 801** клиент совершил две и более завершённых покупок;
- Repeat Purchase Rate (среди купивших) составляет **3.00%**;
- анализ статусов заказов показал, что не все оформленные заказы являются состоявшимися покупками — для расчёта фактических покупок и Retention используется статус `delivered`.
